# Sudharshini M. — Developer Portfolio

A responsive personal developer portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Included sections
- Home hero with supplied profile photograph
- About, education, coursework and achievements
- Resume-based technical skills
- Three projects described in the supplied resume
- Internship section for Cognifyz, Oasis and Syntecxhub
- Contact links, downloadable resume and social profiles
- Dark/light theme switcher
- Reading progress bar at the top of the page
- Responsive mobile navigation

## Files
```text
sudharshini-portfolio/
├── index.html
├── style.css
├── script.js
├── profile-photo.png
├── Sudharshini-M-Resume.pdf
└── README.md
```

## Run locally
1. Extract the ZIP archive.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. No npm installation or build step is required.

## Before publishing
- Review the internship names and role titles for accuracy.
- Add dates and project-specific responsibilities only when confirmed.
- Check the profile image and resume display.
- Confirm all contact links.

## Deploy with Vercel
1. Push all six files to a public GitHub repository.
2. Sign in to Vercel using GitHub.
3. Choose **Add New → Project** and import the repository.
4. Select **Other** as the framework preset.
5. Leave build and output commands empty.
6. Click **Deploy**.
